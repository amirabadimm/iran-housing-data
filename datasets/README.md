# Dataset Catalog

Each dataset is an independent package within its research subject. Provider details belong in dataset metadata; the primary hierarchy remains subject-oriented.

This catalog describes the post-redesign structure. The initial July collection had 51 registered datasets and included derived calculations and executable workflows. Those historical entries are not automatically registered packages here. The current `metadata/dataset_registry.csv` records four established packages: CBI monthly monetary data, SCI building inputs, SCI urban CPI, and CBI Tehran monthly transaction prices.

Other subject directories may be scaffolding for collections still to be re-established. Follow [Project Status](../PROJECT_STATUS.md) for history, the current inventory, and remaining work. Before rebuilding an earlier collection, inspect its historical source and definition records and confirm the available evidence; do not treat a missing current package as proof that the data were never collected.
